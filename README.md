# HairOne

Salon and barbershop booking platform with a React Native mobile app and Express API.

## Structure

- `backend/` — Node.js + Express + MongoDB API
- `frontend/` — Expo (React Native) mobile app

## Getting started

### Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

### Frontend

```bash
cd frontend
cp .env.example .env
npm install
npx expo start
```
